# 5-DOF Robotic Arm with Gesture Control
<img width="1536" height="1024" alt="chart" src="https://github.com/user-attachments/assets/fa5f94c0-777f-4528-9a98-490c6c4d024c" />


This project integrates a 5-DOF robotic arm with a Kinect V2 sensor using **ROS 2**, enabling real-time gesture control, digital twinning, and a user-friendly interface.

## Objectives

- **Mechanical Stability**: Redesign the base to remove wobble.
- **ROS 2 Integration**: Implement motion planning and inverse kinematics.
- **Perception & Control**: Use Kinect V2 for hand-gesture-driven control.
- **Mimicry & Gesturing**: Enable "Mimic Mode" for task execution via gestures.
- **Digital Twinning**: Mirror the physical arm in RViz for simulation.
- **User Interface**: Provide an interactive GUI for camera feeds and manual control.

## Achievements

- **Mechanical Stability**: New bearing-holder design eliminated wobble.
- ![CAD](https://github.com/user-attachments/assets/5cc586ff-0f33-4a72-a5fd-d751921e5d98)
